# Dado 3D

Un dado en 3D hecho solo con HTML y CSS. Tocá la pantalla (o apretá espacio) para tirarlo y sale un número del 1 al 6 al azar.

No necesita instalar nada ni usa librerías externas: es un único archivo `index.html`.

## Publicarlo con GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html` y este `README.md`.
3. Entrá a **Settings → Pages**.
4. En **Branch** elegí `main` y la carpeta `/ (root)`, y guardá.
5. En un minuto tu dado queda online en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
